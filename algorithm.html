preferred_intents: ["TENDER_AND_PROCUREMENT"]

Outcome: SILENTLY DROPPED.
Even though the incoming GR has intent TENDER_AND_PROCUREMENT, it was published by Ministry #13 (Mining). Because the contractor only selected Dept #18 (PWD), the strict department boundary immediately rejects this GR.

GATE 3 FAILS • FINE-TUNED INTENT MISMATCH

Candidate User 2 (Mining Officer)

role_preset: "GOVT_OFFICIAL"
preferred_departments: [13] (Mining)
department_intents["13"]: ["TRANSFER_AND_POSTING"]

Outcome: SILENTLY DROPPED.
The department matches (#13), but the user explicitly fine-tuned their subscription to only receive cadre transfers. Because this GR has intent WELFARE_AND_SUBSIDY, it is filtered out at Gate 3.
